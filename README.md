# МАВ — ведомость по остаткам ТМЦ

Веб-ведомость складских остатков (краски, грунтовки, эмали) по выгрузке
`Ведомость мав.xlsx`. Исходный файл — это Excel/OOXML, не архив с кодом:
макросов и формул в книге нет.

Период: **01.10.2025 — 19.10.2026**. Склад: **Кореличи**.

## Что умеет приложение

- Таблица 111 номенклатур: остатки, приход, расход, мин. резерв, 13 месяцев.
- Подсветка позиций ниже резерва и с нулевым остатком.
- Поиск, фильтры, сортировка, CSV, печать.
- Кнопки **Обновить** и **Настройка** (в Excel они были нерабочими фигурами).

## Локальный запуск

```bash
python3 tools/extract_xlsx.py
cd web
npm ci
npm test
npm run dev
```

Сборка статики: `cd web && npm run build` → каталог `web/dist`.

## Автосборка GitHub Actions

Каждый `push` и `pull_request` запускает `.github/workflows/ci.yml`:

1. распаковка xlsx и сверка JSON;
2. python-тесты целостности данных;
3. vitest + production-сборка Vite;
4. на push — публикация GitHub Pages.

После изменений достаточно закоммитить и сделать `git push` — сборка стартует сама.
