# МАВ — ведомость по остаткам ТМЦ

Веб-ведомость складских остатков (краски, грунтовки, эмали, фурнитура) по выгрузкам `*.xlsx`. Исходные файлы — это Excel/OOXML, не архив с кодом: макросов и формул в книгах нет.

- **Старый файл:** `Ведомость мав.xlsx` — 111 позиций, период 01.10.2025 — 19.10.2026, склад Кореличи, 13 месяцев (K–W).
- **Актуальный файл:** `Ведомость с периодом ОК (1).xlsx` — **1850 позиций**, период **окт 2023 — окт 2026 (37 мес., L–AV)**, склады Кореличи + Мир, группы «2 краски растворители» / «2 замки фурнитура», область `A1:AV1857`.

Столбец Excel **H (8-й)** — пустой в исходнике — теперь заполнен «**К закупке**» на основании сезонной статистики продаж (см. `docs/SEASONAL.md`). Столбец Excel «мин. резерв» игнорируется: норма считается по сезонным продажам.

## Что умеет приложение

- Таблица 1850 номенклатур: остатки, приход, расход, **сезонный резерв**, **к закупке**, 37 месяцев.
- Поиск, фильтры по складу/группе, отбор «к закупке / нулевые», сортировка, CSV, печать.
- KPI: позиций, конечный остаток, сезонный резерв (ноя–дек 2026), к закупке, нулевые остатки.
- График сезонного профиля (помесячные продажи).
- Кнопки **Обновить** и **Настройка** (в Excel они были нерабочими фигурами) — в веб-приложении работают.
- Деталь позиции показывает поставщика, цену последнего поставщика и розничную цену (для нового формата).

## Локальный запуск

```bash
python3 tools/extract_xlsx.py          # распаковать xlsx + JSON (авто-детект формата)
python3 tools/extract_xlsx.py --fill-purchase  # заполнить столбец H «К закупке» в xlsx
python3 -m unittest discover -s tests -v
cd web && npm ci && npm test && npm run build
cd web && npm run dev                  # http://0.0.0.0:5173
```

Сборка статики: `cd web && npm run build` → каталог `web/dist`.

## Автосборка GitHub Actions

Каждый `push` и `pull_request` запускает `.github/workflows/ci.yml`:

1. распаковка xlsx и сверка JSON (`tools/extract_xlsx.py --verify`);
2. python-тесты целостности данных;
3. vitest + production-сборка Vite;
4. на `push` — публикация артефактов и GitHub Pages.

После изменений достаточно закоммитить и сделать `git push` — сборка стартует сама.
