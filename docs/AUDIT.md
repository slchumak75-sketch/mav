## Что это за «архив»

Оба файла — пакеты Office Open XML (ZIP), не архивы с исходниками. Выгрузка отчёта «Ведомость по остаткам ТМЦ на складах», не программа.

- **Новый (актуальный):** `Ведомость с периодом ОК (1).xlsx`
- **Старый (архив):** `Ведомость мав.xlsx`
- Исходник нового найден в репозитории `slchumak75-sketch/Ostatki-` (`Ведомость с периодом ОК (1).xlsx`, 435 551 байт, SHA-256 см. `source/xlsx/MANIFEST.txt` и `data/vedomost.json` meta.sourceSha256). Скачан через `gh api .../contents/... -H Accept: application/vnd.github.raw` и размещён в корне `mav`.
- Оба без `vbaProject.bin` (макросов нет).

Автор в meta (оба): Slava Chumak; последняя правка: «сидор Сидоров». Приложение: Microsoft Excel 14. Лист: `Лист_1`.

## Код / формулы

- Формул в ячейках: **0** в обоих файлах (проверено поиском `<f>` в `xl/worksheets/sheet1.xml`).
- VBA / макросы: **нет** (нет `vbaProject.bin`).
- Кнопки «Обновить» и «Настройка»: DrawingML-прямоугольники (`xl/drawings/drawing1.xml`), `macro=""`. В Excel ничего не делают; в веб-приложении работают как кнопки.

## Целостность цифр (новый)

- Строк: **1850**.
- `Конечный остаток` может быть нулём у 946 позиций (51% нулевых).
- Инвариант `начальный+приход−расход=конечный` неприменим (начальный/приход в новом формате отсутствуют). `balanceOk` всегда true.
- Сумма помесячных `L–AV` **не равна** `F=Расход` у 828 из 1850 — не ошибка парсера, разные разрезы 1С (месяцы = продажи по периодам, Расход = движения). Приложение показывает оба факта и не пересчитывает одно из другого.

- Старый: колонка `J «Минимальный резерв»` есть, но не норма закупки — игнорируется, считается сезонный резерв из `K–W`.

## Распаковка и проверка

```bash
python3 tools/extract_xlsx.py --unpack-only  # только в source/xlsx/
python3 tools/extract_xlsx.py                # + data/vedomost.json
python3 tools/extract_xlsx.py --verify       # сверить JSON с диском (падает если рассинхрон)
python3 tools/extract_xlsx.py --fill-purchase # заполнить H и пересобрать xlsx
```

`python3 tools/extract_xlsx.py` кладёт XML в `source/xlsx/` и пишет `MANIFEST.txt` (список частей + SHA-256). Авто-детект формата по `F7`.

## Проверка кода

- Никаких скрытых скриптов, макросов, внешних связей в OOXML нет — только 12 частей `[Content_Types].xml`, `_rels/.rels`, `xl/...`, `docProps/...`, `theme`, `styles`, `drawings`.
- Приложение не исполняет Excel-логику — парсер на stdlib безопасно читает литералы.
