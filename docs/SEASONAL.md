# Сезонный резерв и закупка

Столбец Excel «Минимальный резерв» **игнорируется**. Норма запаса считается
из помесячных продаж (колонки K–W).

## Дата и горизонт

- Дата расчёта = `meta.periodTo` = **2026-10-19**.
- Октябрь 2026 считается закрытым (отчёт на эту дату).
- По умолчанию горизонт **2 следующих календарных месяца**: ноябрь и декабрь 2026.
- Горизонт 1 / 2 / 3 / 4 / 6 мес. меняется в «Настройка».

## Формулы

```
typical[месяц] = среднее продаж этого календарного месяца в выгрузке
                 (октябрь = среднее окт-2025 и окт-2026)

сезонный_спрос = Σ typical[месяц] по месяцам горизонта

сезонный_резерв = ceil( сезонный_спрос × (1 + буфер%) )
                  буфер по умолчанию 10%

к_закупке = max(0, сезонный_резерв − конечный_остаток)
```

`minReserve` из xlsx в формулу не входит.

## Почему не σ по всем месяцам

У красок лето 20–27, зима 0–1. Общее СКО было бы «сезонностью в квадрате»
и раздуло бы закупку зимой. Буфер — простой процент к спросу горизонта.
