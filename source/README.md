# source/xlsx

Сюда `tools/extract_xlsx.py` распаковывает актуальный `Ведомость с периодом ОК (1).xlsx` (после `--fill-purchase` — с заполненным столбцом H «К закупке») и архивный `Ведомость мав.xlsx`.

Не редактировать XML вручную: при следующем `extract` каталог перезаписывается. Канон для приложения — `data/vedomost.json` (1850 позиций, 37 мес). `MANIFEST.txt` содержит список частей ZIP и SHA-256 исходного xlsx.
